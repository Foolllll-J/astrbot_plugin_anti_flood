## 💡 简介

一款为 [**AstrBot**](https://github.com/AstrBotDevs/AstrBot) 设计的 QQ 群消息整理插件。支持自动处理超长消息，也支持手动将一段聊天快速整理为合并转发记录，既能减少刷屏消息对其他群友的干扰，也方便把群聊内容分享出去。

---

## 🚀 功能特性

* **📏 长消息自动折叠**: 消息达到文字长度或图片数量阈值后，自动合并转发并撤回原消息
* **🧩 按数量手动折叠**: 引用消息或直接发送指令，快速整理指定数量的历史消息
* **↔️ 按端点手动折叠**: 使用两次 `折叠端点` 指定聊天范围，适合整理和分享较长的聊天记录
* **👥 按用户筛选**: 通过艾特一个或多个用户，只折叠这些用户发送的消息

## 📖 使用指南

> [!CAUTION]
> * 手动折叠指令仅限 Bot 管理员使用。
> * 自动处理群员长消息前会检查机器人在 QQ 群中的权限；权限不足时会跳过。

### 📏 自动折叠长消息

启用插件后，群员发送的消息达到配置的文字长度或图片数量阈值时，插件会自动将消息合并转发，并尝试撤回原消息。

### 🧩 按数量折叠

需要分享前面一段聊天记录时，直接用引用消息配合折叠指令即可快速生成一条合并转发消息。

**格式**:

```
/折叠 [数量] [@用户 ...]
```

**示例**:

```
/折叠
/折叠 20
/折叠 20 @小明 @小红
```

- 引用消息发送 `/折叠`：以引用消息为末端，向前折叠默认数量条消息（包含引用消息）。
- 不引用消息发送 `/折叠` 或 `/折叠 20`：以当前指令消息为末端，折叠它之前最近的消息，指令消息本身不会被折叠。
- 艾特一个或多个用户：只折叠这些用户发送的消息；多个用户按并集计算。
- 不填写数量时使用配置中的默认折叠数量，实际找到的消息不足时按实际数量处理。

### ↔️ 按端点折叠

**格式**:

```
/折叠端点 [@用户 ...]
```

**使用方法**:

1. 在一条消息上引用发送 `/折叠端点`，或直接发送指令作为第一个端点。
2. 根据提示引用另一条消息，或直接发送第二次 `/折叠端点`。
3. 插件会折叠两条端点确定范围内的消息，端点先后顺序没有区别。

两次端点指令中的艾特用户会合并计算；如果两次都没有艾特，则不限制消息发送者。
